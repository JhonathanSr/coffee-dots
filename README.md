###COFEE-DOTS ☕

Welcome to my personal Hyprland configuration. These dotfiles are meticulously crafted and performance-tuned for CachyOS, featuring a sophisticated dark aesthetic and a TUI-centric workflow.

This setup is a deeply refined evolution of the OmarArch base, re-engineered to meet my specific needs as a developer and optimized for my hardware.


##System Specs

Optimized for the following hardware:

    OS: CachyOS

    CPU: Ryzen 5 5600X

    GPU: AMD Radeon RX 6600 XT

    WM: Hyprland
